# Predictive Analytics Using Historical Data

## Objective

To forecast future sales trends using historical sales data.

## Tools Used

* Python
* Google Colab
* Scikit-learn
* Matplotlib

## Project Description

This project uses historical monthly sales data to predict future sales trends using a Linear Regression model.

## Methodology

1. Collected historical sales data.
2. Applied Linear Regression for prediction.
3. Forecasted future sales for upcoming months.
4. Visualized historical and predicted trends using graphs.

## Expected Outcome

The model predicts future sales patterns and helps in understanding future business trends.
